# Impeccable pack setup

Source: [pbakaus/impeccable](https://github.com/pbakaus/impeccable) by Paul Bakaus (`plugin/skills`), pinned to one commit. License: Apache-2.0.

- **Once per project:** `/impeccable init`. It reads the code, asks what it cannot infer and writes `PRODUCT.md`. Ask the owner before it writes.
- **Detector CLI.** `npx impeccable detect <path or URL>` needs Node; a rendered page uses the installed Chrome or Edge. It needs no LLM and no API key.
- **Live mode.** `/impeccable live` opens the running dev server with an overlay and writes an accepted variant back to the source. Start it only on a yes.
- Keys and MCP servers: none stated.
