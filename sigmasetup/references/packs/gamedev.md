# Game Dev pack setup

Source: [gamedev-skills/awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills) pinned to one commit. 79 skills for 12 engines plus `router`, which picks the 2 or 3 skills a request needs. License: Apache-2.0. Its `performance-optimization` skill is not installed: the `agent-skills` pack owns that name.

- **The engine you build in.** Each skill names its engine (Godot, Unity, Unreal, Ebitengine, Bevy, Phaser, PixiJS, three.js, Defold, LÖVE, pygame, Roblox); the engine itself is your install. The engine versions it was checked against: its `docs/VERSION-SUPPORT.md`.
- Keys, MCP servers and repo files: none stated. Start with `router` when you do not know which skill fits.
