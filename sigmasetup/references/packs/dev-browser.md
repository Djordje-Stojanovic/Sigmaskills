# Dev Browser pack setup

Source: [SawyerHood/dev-browser](https://github.com/SawyerHood/dev-browser), pinned to one commit. License: MIT.

- Machine, once: `npm install -g dev-browser` (or `bun add -g dev-browser`). Run `dev-browser install` only when the first run says "No Chrome found". Undo: `npm uninstall -g dev-browser`.
- It drives a real Chrome with its own profile; the owner signs in there when a task needs a login.
- Keys and MCP servers: none stated.
