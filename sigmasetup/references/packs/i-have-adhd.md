# I Have ADHD pack setup

Source: [ayghri/i-have-adhd](https://github.com/ayghri/i-have-adhd), pinned to one commit. License: MIT.

- Setup: none. The owner turns it on by name (`/i-have-adhd`); it stays on for the session until "stop adhd mode" or "normal mode".
- The upstream `SessionStart` hook that loads it in every session comes with the plugin, not with the installed skill. To have it always on in one repo, add one line to `AGENTS.md`: answer in the `i-have-adhd` style. Undo: delete the line.
- Keys and MCP servers: none.
