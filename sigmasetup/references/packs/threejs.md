# Three.js pack setup

Source: [CloudAI-X/threejs-skills](https://github.com/CloudAI-X/threejs-skills).

- The skills target `three@0.186`, React Three Fiber 9.8, drei 10.7 and gltf-transform 4.5 (`README.md`). Check the repo's `package.json`; add `three` (and R3F or drei when the project uses React) only on a yes.
- `threejs-asset-pipeline` runs `npx @gltf-transform/cli`, so it needs Node.
- Keys, MCP servers and repo files: none stated.
