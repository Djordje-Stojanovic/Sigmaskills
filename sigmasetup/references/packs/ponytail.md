# Ponytail pack setup

Source: [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) by Dietrich Gebert, pinned to the release tag `v5.3.3`. License: MIT.

- Setup: none. An optional `~/.config/ponytail/config.json` or `PONYTAIL_DEFAULT_MODE` sets the default level; nothing is required.
- **Plugin extras.** The pack installs the six skills. The band above the prompt and the session-start mode come from the plugin: `npx @djordje-stojanovic/sigmaskills ponytail --project .` turns it on for one project (Claude Code, Codex, Pi). Offer it; do not run it unasked.
- Keys and MCP servers: none stated.
