# Local pack setup

A folder of the owner's own skills on this machine.

- Point the installer at it: set `SIGMA_LOCAL_SKILLS_DIR`, or `dirs.local` in the installer config (see `docs/installer.md`, "Your own packs").
- Each skill in that folder carries its own setup. Read its `SKILL.md` for files, tools or keys it names, and offer only those.
- Removal: uninstall the skills; the folder itself is the owner's and stays.
