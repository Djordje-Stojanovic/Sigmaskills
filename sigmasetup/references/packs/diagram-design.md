# Diagram Design pack setup

Source: [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design) by Cathryn Lavery, pinned to one commit. License: MIT.

- Setup: none. A diagram is plain HTML and SVG with no build step, JavaScript or external image.
- **Optional:** "Onboard diagram-design to <site URL>" pulls that site's palette and fonts so later diagrams match. Run it only when the owner names the site.
- Keys and MCP servers: none stated.
