# Anatomy pack setup

Source: [wheresryan22/anatomy](https://github.com/wheresryan22/anatomy) pinned to one commit. The skill is the repo root itself. License: MIT.

- **Node 20.10 or later.** Check with `node --version`. The kit uses only Node's built-in modules: nothing to `npm install`.
- Keys and MCP servers: none. `scripts/publish.mjs` opens a pull request to the Anatomy gallery on GitHub (`gh`), only when the user asks.
