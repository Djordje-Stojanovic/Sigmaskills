# Taste pack setup

Source: [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) pinned to one commit. License: MIT.

- **Node 22+** and an installed **Chrome, Edge or Chromium**. Set `CHROME_PATH` when the browser is in an unusual place. Check with `node --version`.
- **Optional:** `ffmpeg` on the PATH, for WebP output and the phone crop of a hero photograph.
- The scripts install nothing and need no API keys. The bundled photographs work offline; fetching more photographs or icons uses the network.
