# One bold place

## What it sees

Where the boldness is spent. Name the one memorable element. Two elements shouting is a finding; none is also a finding. Then name the one thing to cut ("look in the mirror and remove one accessory"). Restraint still needs a point of view: bare grey type on a plain ground is the generic quiet look, and a frame that reads as an unfinished wireframe is underbuilt, not restrained.

## Tells

- Every section has a gradient, an illustration, a badge and an animation.
- Every line of copy tries to land a punch, so none does.
- A bare page with small text in a big empty field, one motif enlarged, nothing to read.
- A refinement pass that added things (a new filter, a new shape) instead of sharpening what was there.

## Fix moves

- Choose the bold place from the subject (see [only this one](only-this-one.md)): a huge headline set with intent, one real image full bleed, one live demo, one striking number.
- Quiet everything around it: fewer colours, less motion, plain components.
- Cut one decoration per screen. If space opens up, fill it with scale or real content, never another ornament.
- In copy, ration the punch: one or two bold lines per page, the rest plain and specific.
- On a second pass, ask "how do I make what is here more of itself?" before adding anything.

## Verify

- Name the bold place in one sentence after the change. If you need two, cut one.
- Before and after screenshot: the after has fewer elements and a clearer lead.
