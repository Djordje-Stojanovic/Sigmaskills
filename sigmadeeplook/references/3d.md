# 3D files

glb and gltf, stl, obj, ply, usd (text), fbx and blend (headers only). A model is geometry plus materials; the look measures the geometry and shows it from six fixed views.

## When look.py is not enough

- FBX and `.blend` need a real reader. The look gives the header and version and a Not-looked-at row. Blender can convert them headless (`blender -b file.blend --factory-startup -Y --python script.py`); never run an untrusted file's own scripts, which is why `-Y` (no auto-run) is mandatory.
- Materials, animation, rigs and shaders: described from the glTF JSON only. Judging how it looks needs the views and a human.
- Real-time quality (draw calls, texture memory): `gltf-transform inspect` and the Khronos validator. Name them; they are Node tools, not bundled.
- USD binary (`.usdc`, `.usdz`): needs OpenUSD tools (`usdcat`, `usdchecker`).

## Pipeline

1. Identify: `glTF` magic, JSON start, STL size rule (80 + 4 + 50 x count) against `solid`, OBJ lines, `ply`, `#usda`, `Kaydara FBX Binary`, `BLENDER`.
2. Stdlib parse (`model.json`): GLB JSON chunk (nodes, meshes, materials, textures, accessors, triangle count, bounding box); STL (count, bounds, watertight edge check up to 2 million triangles); OBJ and PLY counts, bounds, materials from `.mtl` names.
3. glTF validity checks written to `validate.json` (`GLTF-INVALID`, `MISSING-TEXTURE`). Not a replacement for the Khronos validator.
4. Watertight: every edge shared by exactly two triangles. If not, `NOT-WATERTIGHT`: volume and centre of mass are meaningless.
5. Views: a Pillow software renderer (flat shading, painter's algorithm, at most 200,000 triangles sampled) gives `views/front.png`, `right`, `back`, `left`, `top` and `iso` (orthographic), and a sheet `sheet-views.jpg` at 2000 px. Without Pillow: a Not-looked-at row.
6. With Blender installed and the human's yes, a Blender render can replace the software views. Always `--factory-startup -Y`.

## Failure modes

- A non-watertight mesh has no meaningful volume.
- STL has no units and no colour in the standard. A bounding box of 2 may be 2 mm or 2 m. Ask.
- OBJ has no animation, skinning or hierarchy; materials sit in an external `.mtl` that may be missing.
- `trimesh.load_mesh` joins scene instances; instances matter for glTF.
- Validator warnings (non-power-of-two textures) are not errors.
- Software views show geometry, not materials or lighting. A dark or odd look is the renderer, not the model.
- Dense meshes: the renderer samples triangles and says so (`SAMPLED`).
- A file that only references external textures or buffers loads none of them; the look lists what is missing.

## Show the human

Format and size, triangle count, bounding box with the unit question, watertight yes or no, material and texture counts and any missing, the validator list, the six views and the sheet. Name any converted file: conversion can change materials. Ask: the unit, the intended use (print, real-time, render), and whether FBX or Blender conversion is allowed.

## Install (Win/Linux/macOS)

Nothing is required for glb, gltf, stl, obj and ply. Pillow draws the views: `pip install pillow`.

- Optional: Blender `winget install BlenderFoundation.Blender` / `sudo apt install blender` / `brew install --cask blender`.
- Optional: `npm install --global @gltf-transform/cli`.
